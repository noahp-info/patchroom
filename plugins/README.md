# Plugins

First-party plugins will live here. They dogfood the same plugin format third parties use (Claude Code marketplace layout plus a `patchroom` manifest block). See [docs/SPEC.md](../docs/SPEC.md) section 3.9.

Planned:

- Theme packs, including Slack theme-string import
- Sound packs
- Importers (terminal settings, running sessions)
- Artifact viewers
- Non-Claude adapters (Cursor, Gemini, Copilot, opencode, Codex)

Nothing here yet. The plugin host lands in phase P6.
